# Movie Site App

A full-stack movie collection website built with HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

## Features

- 🎬 Browse movie collection
- 🔍 Search and filter movies
- ➕ Add new movies
- ✏️ Edit existing movies
- 🗑️ Delete movies
- 📱 Responsive design

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Version Control**: Git & GitHub
